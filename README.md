# Charinco Search

アイデアは、一見関係のない知識の組み合わせから生まれるといわれます。しかし、流行や傾向から「もっともらしい」答えを返す今日の検索エンジンやAIは、私たちを知っていることの延長線上に留めてしまいます。『Charinco Search』は、「平行にずらす」検索の仕組みと、図書館を逍遥するようなUI、サイトの切り抜きを集めるスクラップブックの機能によって、創作のための寄り道を取り戻す検索エンジンです。

## 3つの要素

| 要素 | 実装 |
|---|---|
| **仮想図書館ビュー** | 日本十進分類法（NDC）の 0〜9 の書架が並び、どの書架にも本が入る。背表紙は縦書きで、書架は横スクロール（ホイール / ←→キー）で歩き回る。書架内は背表紙の五十音順で、関連度順には並べない。検索結果が届いた書架から順に本が埋まっていく。 |
| **平行サジェスチョン** | Claude が検索語の属する書架を1つ判定し、残り9つの書架それぞれへ「同じ構造／別の時代／別の場所／別の分野／反例・対立／スケール違い」のいずれかでずらした検索語を作る。背表紙上端の色帯でずらし方が分かる。司書のコメントの「この言葉で探しなおす」と、本の「この本からずらす」で寄り道が続き、上部に〈寄り道の記録〉が残る。 |
| **HTMLスクラップボード** | 本を手に取り「切り抜く」と、ページを段落・見出し・画像・表の単位で表示する。クリックした部分、またはドラッグで囲んだ範囲（枠に掛かった要素すべて）をプレビューで確かめてから、ボードにカードとして貼る。カードにはコメントを付けられる（プレビューで書くか、ボード上の「＋ コメント」から）。付箋の追加と、カード同士を線でつなぐ操作ができる。ボードは拡大縮小（ボタン、Ctrl/⌘+ホイール、ピンチ、+ − 0 F キー）と、何もない所のドラッグでの移動ができる。ボードは複数作れて、ボードの上のタブで切り替える（＋ で新規、タブのダブルクリックでその場で名前変更、× で削除。全部削除して0枚にもでき、そのときに切り抜いて貼ると「ボード 1」が自動でできる）、1つずつ .json ファイルに「書き出す」／「読み込む」（新しいボードとして増える）ことができる。ボードはブラウザ（localStorage）に保存され、容量はブラウザ全体でおよそ5MB。切り抜き画面で開いたページはタブで並び、閉じても上部の「開いているページ」から開き直せる。 |

ブラウザの「戻る／進む」で、検索結果・タブ（図書館／スクラップボード）・本の説明・切り抜き画面を行き来できます。

## 構成

```
public/        フロントエンド（素のHTML/CSS/JS、ビルド不要）
  clipcore.js  切り抜きの中核（範囲の要素集め・見た目ごとの書き出し）。裏の Chrome のページでも同じものを動かす
  vendor/      DOMPurify 3.1.6（npm の dompurify と同じファイル。外の CDN に頼らず起動できるよう同梱）
api/           サーバーの API（server.mjs が呼び出す）
  parallel.js  平行サジェスチョン：元の書架の判定と、他の9書架へのずらし（Claude）
  search.js    Web検索（Brave Search API）。動画・SNS・ECの商品ページ・PDFなど、切り抜けない結果は lib/filter.js で除く
  clip.js      スクラップ用のページ取得（サニタイズはブラウザ側の DOMPurify）
               mode=render のときは、手元の Chrome で実際に表示してから写し取る（lib/render.js）
  asset.js     切り抜き画面用に、元サイトの CSS とWebフォントを中継（アイコンや書体の崩れを防ぐ）
  live.js      ライブ表示：裏の Chrome のタブの画面を流し、クリック・スクロール・キー入力を中継する（lib/live.js）
lib/           共通処理
  net.js       外のサイトを取りに行くときの安全確認（手元のネットワークへは行かせない）と、リダイレクトをたどる取得
  render.js    裏の Chrome で表示して写し取る ／ live.js  ライブ表示のタブ操作
  claude.js    平行サジェスチョン（Claude） ／ brave.js  Web検索 ／ filter.js  切り抜けない結果を除く
  http.js      API の受け答え ／ errors.js  エラー ／ cache.js  件数に上限のある覚え書き ／ mock.js  ダミーデータ
extension/     Chrome 拡張機能「Charinco 切り抜き」（ふつうのタブの上で切り抜いてボードに送る）
server.mjs     サーバー（http://localhost:3000）
```

- AI: Claude Opus 5.5（`claude-opus-5-5`、effort: low、JSON Schema による構造化出力）
- 検索: [Brave Search API](https://brave.com/search/api/)

## ローカルで動かす

```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY と BRAVE_API_KEY を記入
npm run dev            # http://localhost:3000
```

APIキーがなくても `npm run mock` を使えば、ダミーデータで画面と操作を確認できます。

### 拡張機能「Charinco 切り抜き」（おすすめ）

ふつうの Chrome で見ているページの上で、そのまま切り抜けます。切り抜いたものは、開いている Charinco のスクラップボードに届きます。

入れ方（最初の1回だけ）:

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダの中の `extension` フォルダを選ぶ
3. Charinco のタブを読み込み直す

使い方:

- 本の説明で「切り抜く」を押すと、隣のタブでページが開き、右下に Charinco のツールバーが出ます。
- 「✂ 切り抜き」（C キー）で切り抜きモード。クリックでブロックを選び（↑↓で広げる・狭める）、ドラッグで範囲を囲みます。プレビューでコメントを付けて「ボードに貼る」。
- どのページでも、ツールバーの拡張機能アイコン（または Option+Shift+C）で切り抜きを始められます。
- ツールバーは、使うタブにだけ読み込みます（Charinco から開いたタブと、アイコンを押したタブ）。ふだん見ているページには何も入れません。
- ツールバーの「図書館へ」「ボードへ」で、Charinco のタブのその画面へ移れます。
- 拡張機能が動いているときは、Charinco のヘッダーに「✂ 拡張機能で切り抜き中」と出て、「開いているページ」は隠れます。
- Charinco のタブが閉じていても、切り抜いたものは取っておき、次に開いたときに貼ります。
- 拡張機能が入っていないときは、下の「ライブ表示」で切り抜き画面が開きます。
- `extension/clipcore.js` は `public/clipcore.js` の写しです（サーバーの起動時に自動で同じ内容にします）。

### 切り抜き画面の「ライブ表示」

切り抜き画面では、Mac にインストールされた Google Chrome をサーバーが裏で（画面なしで）起動し、
そのタブの画面をそのまま映します。ふつうのブラウザと同じく JavaScript が動くので、見た目は崩れません。

- 閲覧モードでは、クリック・スクロール・文字入力（日本語も可）・リンク移動がそのまま使えます。バーの ← → ↻ で戻る・進む・再読み込み。
- 切り抜きモードでは、本物のページの中で要素を選び、元の見た目のままカードにします（クリック、↑↓で範囲調整、ドラッグで範囲選択）。貼った部分にはページ上で枠が付きます。
- 本を手に取った時点で裏のタブを開き始めるので、「切り抜く」を押す頃には表示できていることが多いです。
- 画面は、切り抜き画面で見ている間だけ流します（1秒に30枚まで）。先に開いておいただけのタブでは画像を作りません。
- 裏のタブは最大5つまで。しばらく使わないタブは閉じ、また開いたときに読み込み直します。
- 広告・アクセス解析・Cookie 同意バナーは読み込みません。
- 「読みやすい表示にする」では、本文だけを取り出した表示に切り替えられます。

### Chrome が使えないときの「再現表示」

Chrome を起動できない環境では、ページのスクリプトが動いた後の姿を写し取って表示します（スクリプトは動きません）。

- 写し取りには数秒〜25秒ほどかかるため、まず取得したままの HTML で表示し、再現版が届いた時点で自動で差し替えます（すでに切り抜いた後は差し替えません）。
- 本を手に取った時点で準備を始めるので、説明を読んでいる間に終わることが多いです。
- 記事一覧などをスクリプトで後から読み込むサイトでは、その読み込みが終わるまで待ってから写し取ります。
- フォント・動画・広告・アクセス解析・Cookie 同意バナーは写し取りの際には読み込みません。画像は「読み込めた」ことにして中身を省きます（本物は表示する側が読みます）。
- Chrome のキャッシュは一時フォルダ（`charinco-chrome-ポート番号`）に残すので、同じサイトの2ページ目からは速くなります。
- Chrome の場所が違う場合は `CHROME_PATH` で指定できます。`CHARINCO_RENDER=0` で再現表示を止められます。

## 1回の検索で行う処理

元の語の検索と平行ずらしを同時に始める → 書架を先に表示する → ずらした9語を同時に検索し、届いた書架から本を並べる（合計約60冊）。
Claude の呼び出しは1回、Brave の検索は10回です。同じ検索語の結果はサーバーが覚えているので、2回目以降はすぐに表示されます。
